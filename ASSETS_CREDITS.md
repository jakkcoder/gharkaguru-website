# Assets credits (stock images)

GharKaGuru uses **remote stock images** (for a richer, less “plain” UI) from **Unsplash**.

If you need a fully offline / fully self-hosted deployment, replace the URLs in:
- `src/assets/stockImages.ts`

and store the files under:
- `public/assets/…`

Then update the URLs accordingly.

**Image source**: Unsplash (`https://unsplash.com/`)

Notes:
- These images are used as *visual placeholders* in the frontend demo.
- If your organization requires strict attribution/legal review, replace them with approved assets.
